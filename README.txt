WorkersPlaces 0.3.0
Schedule I worker idle positions

INSTALL

1. Install MelonLoader for the default IL2CPP version of Schedule I.
2. Close the game. Extract this ZIP into the Schedule I game folder.
3. Confirm that the file is at Schedule I/Mods/WorkersPlaces.dll.
4. Start the game. No S1API installation is required.

USE

Open the management clipboard with exactly one botanist, chemist, cleaner, or packager selected. In the Idle position panel, choose Set or Change. Walk to the desired spot, face the direction the worker should face, and press Space. The mod saves the spot and facing direction, teleports the worker there, and turns the worker to face that direction.

Press Escape or right-click to cancel placement. Choose Clear to restore the worker's normal idle destination. Clear does not move the worker back immediately.

Only the host can change worker positions. Teleporting a worker does not cancel an active job, so the worker may walk away to continue working. The mod does not check navigation paths. Teleporting someone into an unreachable area does not make their job or route work there.

SAVED DATA AND REMOVAL

Positions are stored per game save under Schedule I/UserData/WorkersPlaces. The mod does not edit the game's save files. To remove the mod, close the game and delete Mods/WorkersPlaces.dll. The saved position files can be deleted separately if no longer wanted.
